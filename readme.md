# Maya to Unreal Automation Pipeline

A toolset that bridges Autodesk Maya and Unreal Engine to automate asset preparation, material creation, and scene hierarchy reconstruction.

## Problem

When importing complex models, Maya converts special characters into ASCII escape codes (e.g., `FBXASC038`, `FBXASC032`). This results in unreadable naming in the Outliner. Artists then waste hours manually renaming meshes and dragging-and-dropping materials in Unreal Engine.

This pipeline solves both problems with a two-script workflow.

---

## Files

| File | Description |
|------|-------------|
| `maya_asset_exporter.py` | Maya Python tool — cleans names, extracts materials, exports JSON |
| `unreal_scene_builder.py` | Unreal Python tool — parses JSON, spawns meshes, assigns materials |
| `jsonData.json` | Sample exported JSON (generated by Maya script) |
| `uploads_files_5826800_basket+ball.fbx` | Sample FBX test model |

---

## Requirements

### Maya
- Autodesk Maya 2020+ (Python 3)
- No third-party plugins required

### Unreal Engine
- Unreal Engine 5.x
- **Plugins to enable** (Edit → Plugins):
  - Python Editor Script Plugin
  - Editor Scripting Utilities

## Step 1: Maya — Clean & Export

### Usage

1. Open Maya
2. **File → Import** your FBX file
3. **Select the root transform node** in the Outliner (the topmost group)
4. Open **Window → General Editors → Script Editor** (Python tab)
5. Run:

```python
exec(open(r"C:/Users/ijz1cob/Desktop/Maya/maya_asset_exporter.py").read())
run(r"C:/Users/ijz1cob/Desktop/Maya/jsonData.json")
```

### What It Does

- Strips `FBXASC###` escape codes from all node names
- Removes namespace prefixes (`vehicle:part` → `part`)
- Converts CamelCase to snake_case
- Normalizes all names to lowercase with underscores
- Detects **all material slots** per mesh (multi-material support)
- Extracts PBR parameters: base color, metallic, roughness, specular, opacity, emissive
- Extracts connected texture file paths
- Exports a structured JSON file

### Name Cleanup Examples

| Before (dirty) | After (clean) |
|-----------------|---------------|
| `BasketFBXASC032ball` | `basket_ball` |
| `MaterialFBXASC046001` | `material_001` |
| `body_FBXASC038panel` | `body_panel` |
| `vehicle:wheel_FL` | `wheel_fl` |

---

## Step 2: Export Clean FBX from Maya

After the script runs (names are now clean in the scene):

1. Select the root transform
2. **File → Export Selection** → FBX format
3. Save as the clean FBX (e.g., `basketball_clean.fbx`)

---

## Step 3: Import into Unreal

1. In Unreal, create a folder in Content Browser: `/Game/Meshes/`
2. **Import** the clean FBX into that folder
3. Import settings: ensure **"Combine Meshes"** is OFF (keeps individual meshes separate)

---

## Step 4: Unreal — Build Scene from JSON

### Configuration

Open `unreal_scene_builder.py` and update these paths at the top:

```python
JSON_PATH = r"C:/Users/ijz1cob/Desktop/Maya/jsonData.json"
MESH_SEARCH_PATH = "/Game/Meshes/"
MATERIAL_OUTPUT_PATH = "/Game/Materials/Generated/"
```


### How to Run

**Option A — Output Log (recommended):**

In Unreal Editor, open Output Log, switch to Python, type:

```
py "path to unreal_scene_builder.py"
```

**Option B — Execute Python Script:**

Edit → Execute Python Script → select `unreal_scene_builder.py`

**Option C — Editor Utility Widget (one-click button):**

1. Right-click widget in Content Browser → Run Editor Utility Widget

### What It Does

- Scans Content Browser for imported StaticMesh assets (fuzzy name matching)
- Finds already-imported materials from FBX (reuses them, doesn't duplicate)
- Creates new materials with PBR node graphs if none exist
- Spawns meshes into the level at configured location/scale
- Assigns materials to correct slots (supports multi-material meshes)
- Reconstructs Maya hierarchy using World Outliner folders

## JSON Format Reference

```json
{
  "version": "2.0",
  "scene_name": "group",
  "mesh_count": 1,
  "material_count": 2,
  "meshes": ["basket_ball"],
  "hierarchy": {
    "group": {
      "mesh": null,
      "material_slots": [],
      "children": {
        "basket_ball": {
          "mesh": "basket_ball",
          "material_slots": ["material_001", "leather_procedural"],
          "transform": {
            "translation": [0.0, 0.0, 0.0],
            "rotation": [0.0, 0.0, 0.0],
            "scale": [1.0, 1.0, 1.0]
          }
        }
      }
    }
  },
  "materials": {
    "material_001": {
      "base_color": [0.8756, 0.1106, 0.011],
      "metallic": 0.0,
      "roughness": 0.75,
      "specular": 0.5,
      "opacity": 1.0,
      "texture_maps": {}
    },
    "leather_procedural": {
      "base_color": [0.0, 0.0, 0.0],
      "metallic": 0.0,
      "roughness": 0.5036,
      "specular": 0.5,
      "opacity": 1.0,
      "texture_maps": {}
    }
  },
  "mesh_material_assignments": {
    "basket_ball": ["material_001", "leather_procedural"]
  }
}
```

### Key Fields

| Field | Description |
|-------|-------------|
| `hierarchy` | Nested structure matching Maya's Outliner. Group nodes have `mesh: null`. |
| `material_slots` | Ordered list of materials per mesh (slot 0, slot 1, ...) |
| `materials` | PBR parameters for each material (color, metallic, roughness, etc.) |
| `texture_maps` | File names of connected textures (base_color_map, normal_map, etc.) |
| `mesh_material_assignments` | Flat lookup: mesh name → list of material names by slot |

---

## Important Notes

- **Editor-only**: The Unreal script uses Editor APIs. It must be run in editor context (Output Log, Execute Python Script, or Editor Utility Widget). It does NOT work from Level Blueprint Event BeginPlay.
- **No third-party plugins**: Uses only native Maya cmds and Unreal Python APIs.
- **Multi-material support**: Meshes with multiple materials assigned to different faces are fully supported.
- **Fuzzy asset matching**: The Unreal script searches for meshes by name with multiple fallback strategies, handling prefix mismatches and naming differences.
- **Idempotent materials**: Running the script multiple times won't duplicate materials — it reuses existing ones.

## Troubleshooting

| Issue | Cause | Fix |
|-------|-------|-----|
| "No StaticMesh assets found" | FBX not imported, or wrong `MESH_SEARCH_PATH` | Import FBX first, verify path matches Content Browser |
| Only empty actors spawn | Mesh name mismatch (old JSON vs Unreal asset name) | Re-export JSON from Maya after cleaning, or check single-mesh fallback in logs |
| Scale 100x too large | Maya FBX export applies unit conversion | Set `OVERRIDE_TRANSFORM = True` and `SPAWN_SCALE = (1,1,1)` |
| Materials not assigned | Material names in JSON don't match Content Browser | Script uses fuzzy matching; check Output Log for match attempts |
| Script doesn't run from Blueprint | Editor APIs don't work at runtime | Use Output Log, Execute Python Script, or Editor Utility Widget instead |

## Architecture

```
maya_asset_exporter.py
├── clean_name()                    — Universal FBXASC/namespace/case sanitizer
├── get_all_materials_on_shape()    — Captures ALL shading groups per mesh
├── extract_material_data()         — Reads PBR params from any material type
├── build_hierarchy()               — Recursive DAG traversal + rename
└── export_json()                   — Orchestrates cleanup and writes JSON

unreal_scene_builder.py
├── discover_static_meshes()        — Scans Content Browser for StaticMesh assets
├── discover_existing_materials()   — Finds materials already imported with FBX
├── find_mesh_asset()               — Multi-strategy name matching (exact/fuzzy/fallback)
├── get_or_create_material()        — Reuse existing or create new with PBR nodes
├── spawn_hierarchy()               — Recursive spawner with folder-based grouping
└── run()                           — Main pipeline entry point
```
